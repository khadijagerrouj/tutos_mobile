# Issues GitHub

- Création de 3 Issues avec un titre clair et une description.
- Ajout du label `enhancement`, assignation à moi-même et association au milestone `Sprint 2`.

# Pratique

- L’onglet Issues affiche 3 tickets ouverts.
- Le milestone « Sprint 2 » regroupe les 3 Issues.
- Les 3 Issues sont assignées à moi-même et portent le label `enhancement`.
