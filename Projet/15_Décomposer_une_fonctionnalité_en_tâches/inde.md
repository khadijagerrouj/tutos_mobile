Pour réaliser cette fonctionnalité, j’ai décomposé le travail en cinq tâches principales.

**Première tâche : Préparer le modèle de données**

Je commence par créer la table `categories` avec les colonnes `id`, `nom` et `couleur`.

**Deuxième tâche : Créer l’API CRUD**

Ensuite, je crée l’API qui permet d’ajouter, afficher, modifier et supprimer une catégorie.

**Troisième tâche : Construire le formulaire HTML**

Après, je crée un formulaire avec les champs nécessaires pour ajouter une nouvelle catégorie.

---

**Quatrième tâche : Connecter le formulaire à l’API**

Je connecte le formulaire à l’API avec JavaScript pour envoyer les données.

**Cinquième tâche : Tester et valider**

Enfin, je teste les différentes fonctionnalités pour vérifier que l’ajout, l’affichage, la modification et la suppression fonctionnent correctement.

Les tâches ont des dépendances : certaines doivent être terminées avant de commencer les suivantes.
